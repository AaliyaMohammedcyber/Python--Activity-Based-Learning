# String-Based Examination Answer Evaluation

### 1. Problem Statement

Write a Python program to evaluate a student's examination answers by comparing them with the correct answer key. Award 4 marks for each correct answer and deduct 1 mark for each incorrect answer. Display the final examination score.

### 2. Algorithm

1. Start.
2. Initialize the correct answer key.
3. Get the student's answers.
4. Set score = 0.
5. Compare each student answer with the correct answer.
6. Add 4 marks for correct answers; otherwise, deduct 1 mark.
7. Display the final score.
8. Stop.

### 3. Flowchart
```mermaid
    A([Start]) --> B[/Enter answers/]
    B --> C[Calculate score]
    C --> D[/Display score/]
    D --> E([Stop])
```

### 4. Sample Input

```
Enter your Answers: A C B D
```

### 5. Sample Output

```
Exam Score: 16
```
